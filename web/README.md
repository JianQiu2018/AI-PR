# lottery-web

Vue 3 + fully static frontend (no Node / npm required).

## Run

1. Start the backend (see `server/README.md`) and make sure `http://localhost:8080` is reachable.
2. Enter the `web` directory and run:

```
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Open: `http://localhost:5173`.
